## Categorization & Usage

1. **Canonical Tender Notice (`tenders/`)**:
   - `GEM_2026_B_DEMO_001_Tender.pdf`: Canonical tender notice used for extracting EMD, turnover, experience, warranty, and technical eligibility thresholds.

2. **Canonical Vendor Bid (`bids/`)**:
   - `Apex_Network_Solutions_Technical_Bid.pdf`: Technical bid document submitted by Apex Network Solutions Private Limited.

3. **Supporting Documents (`supporting-documents/`)**:
   - Contains official certificates for ACME, Brightline, and Shady Traders matching GST, Udyam, PAN, EPFO, Startup India, and ISO registries. Used for KYC and document verification.
